# GoreeCloud Identity — Planned Features

The following capability families remain planned until authoritative source, tests, review, and applicable target-environment evidence verify them:

- user identity lifecycle;
- service and workload principals;
- device identity and enrollment context;
- standards-based authentication and federation;
- secure sessions, logout, renewal, and revocation;
- passkey and multi-factor authentication integration;
- account recovery;
- roles, groups, delegated authority, and application registration;
- privacy-minimized security and audit events;
- administrative APIs and Glaze UI;
- directory interoperability where justified;
- backup, recovery, migration, and portability;
- applicable integrations with Manager, Privacy Shield, Wardveil Security, Everkeep, Glaze UI, Mesh, Policy, and Observability.

GoreeCloud Vault remains the protected credential and authenticator authority. Planned Identity capability must not create a competing secret store.
