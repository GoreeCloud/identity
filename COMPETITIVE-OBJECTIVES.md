# GoreeCloud Identity — Competitive Objectives

GoreeCloud Identity is intended to compete on privacy, self-hosting, interoperability, explicit authority boundaries, recoverability, and secure defaults rather than lock-in.

Target objectives include standards-based federation, passkey support, strong session revocation, device and workload identity, administrator-controlled registration by default, minimal claim disclosure, portable configuration, and consistent integration across GoreeCloud applications.

These are objectives, not current implementation claims.
